## About
This is a simple Flutter ToDo List application that stores tasks using the `shared_preferences` plugin. It includes basic persistent storage, unit testing, and mock testing functionalities.

---

## Features
- Add ToDo items
- Persist tasks locally using Shared Preferences
- View saved tasks after restarting the app
- Unit test for Shared Preferences save/load
- Bonus: Mocked unit test using fake Shared Preferences
